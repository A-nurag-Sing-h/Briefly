# Briefly 📰
### AI-Powered Personalized News Aggregator

**Briefly** is a full-stack news platform designed to solve information overload. Unlike traditional news sites, Briefly delivers content tailored specifically to a user's interests—a solution born from my own experience as a government exam aspirant struggling to find a single, filtered source for exam-specific updates.

---

## 🚀 The Goal
To provide a noise-free environment where users receive only the news that matters to them, powered by automated aggregation and interest-based filtering.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Backend:** Node.js, Express.js (ES Modules)
- **Database:** MongoDB with Mongoose ODM
- **Security:** Bcrypt (Password Hashing), JWT (Stateless Authentication)
- **Tools:** Axios (API Fetching), Node-Cron (Scheduled Tasks), Morgan (Logging)

## ✨ Core Features (In Development)
- **Preference Onboarding:** Custom topic selection (e.g., Exam Updates, Tech, Finance).
- **Personalized Feed:** Backend logic that filters news based on saved user preferences.
- **Automated Ingestion:** A background service that fetches and deduplicates news every hour.
- **Bookmarks:** Save important articles for later reading.
- **Social Engagement:** Real-time reactions and comments on news stories.
